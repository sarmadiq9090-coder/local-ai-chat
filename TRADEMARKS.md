Only these are official:

- **GitHub Releases** of this repository:
  <https://github.com/sarmadiq9090-coder/local-ai-chat/releases> (`local-ai-chat.exe`). The
  app's built-in updater downloads only from here.
- **Website**: <https://fastkiwi.app/lemon/>

A copy from anywhere else is not official, even if it uses the Lemon name or icon.

## Reporting impersonation

If you find a copy that uses the Lemon or FastKiwi name or icon and pretends to be official,
please tell us:

- open an issue: <https://github.com/sarmadiq9090-coder/local-ai-chat/issues/new>, or
- use the support page: <https://fastkiwi.app/support/>.

Include the link and, if you can, a screenshot. If the copy contains malware, also report it
privately as described in [SECURITY.md](SECURITY.md).
