## 3. Rust crates (transitive dependencies)

The Windows build pulls in about 200 crates in total. Their licenses, as
declared in each crate's `Cargo.toml`, fall into these groups:

| License expression | Approx. crates | Notes |
|---|---|---|
| MIT and/or Apache-2.0 (incl. dual-licensed) | ~170 | The large majority (tokio, hyper, serde, windows, …). |
| Unicode-3.0 (alone or with MIT/Apache-2.0) | ~25 | ICU4X crates (`icu_*`, `zerovec`, `yoke`, `tinystr`, …) and `unicode-ident`, used for URL/IDNA handling. |
| Unlicense OR MIT | ~4 | `memchr`, `walkdir`, `same-file`, `winapi-util`. Used under MIT. |
| Zlib / BSL-1.0 / 0BSD / CC0 offered as alternatives | ~6 | e.g. `tinyvec`, `miniz_oxide`, `ryu`, `adler2`, `dunce`; always also offer MIT or Apache-2.0. |
| (Apache-2.0 OR MIT) AND BSD-3-Clause | 1 | `encoding_rs` (includes BSD-3-Clause WHATWG data). |
| MIT AND BSD-3-Clause | 1 | `matchit` (axum's router; derived from httprouter). |
| MPL-2.0 | 1 | `option-ext` (dependency of `dirs`). Used unmodified; source available on crates.io. |
| MIT (Microsoft WebView2 bindings) | 3 | `webview2-com`, `webview2-com-sys`, `webview2-com-macros`. `webview2-com-sys` links Microsoft's `WebView2LoaderStatic.lib` from the Microsoft Edge WebView2 SDK, which is distributed under Microsoft's WebView2 SDK license. |

To regenerate the exact list:

```powershell
cargo tree --target x86_64-pc-windows-msvc -e normal --prefix none --format "{p} {l}"
```

No crate in the shipped binary is licensed under a copyleft license that
applies to the whole program (GPL/LGPL/AGPL). `MPL-2.0` is file-level copyleft
and only applies to `option-ext`'s own source files.

## 4. Not bundled: Microsoft Edge WebView2 Runtime

The app renders its UI with the WebView2 Runtime that ships with Windows 10/11
(or is installed separately by the user). It is a Microsoft component under
Microsoft's own license terms and is **not** redistributed by this project.

## 5. Not bundled: Ollama and AI models

Lemon is a client for [Ollama](https://ollama.com). **Neither Ollama
nor any model is included in this repository or in the release executable.**

- Ollama is installed separately by the user and is licensed under its own
  terms (MIT at the time of writing).
- Every model you download ("pull") through the app is fetched by Ollama from
  its registry. **Each model has its own license** (for example Apache-2.0,
  the Llama, Gemma or Qwen community licenses, …) which you accept when you
  pull and use it. Check the model's page on
  [ollama.com/library](https://ollama.com/library) before using a model,
  especially for commercial use.
- Model names suggested in the app's model catalog are recommendations only;
  this project does not grant any rights to those models.
